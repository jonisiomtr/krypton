## 🚀 Cadastro e Login

### Como criar uma conta?

1. Acesse `https://seudominio.com`
2. Clique em "Criar Conta"
3. Preencha:
   - Nome de usuário (será o ID da sua empresa)
   - Nome da empresa
   - E-mail
   - Senha
   - Confirme a senha
4. Clique em "Enviar Código"
5. Você receberá um código por e-mail
6. Digite o código
7. Sua conta será criada automaticamente

### Esqueci minha senha

1. Na tela de login, clique em "Esqueci minha senha"
2. Digite seu e-mail
3. Você receberá instruções para redefinir
4. Entre em contato com o suporte se não funcionar

### Posso mudar meu nome de usuário?

Não, o nome de usuário é o ID da sua empresa e não pode ser alterado. Se precisar mudar, entre em contato com o suporte.

## 📱 WhatsApp

### O QR Code não aparece

**Possíveis causas:**
1. O módulo WhatsApp não está ativo
2. A conexão está demorando para gerar
3. O WhatsApp está com problemas

**Soluções:**
1. Verifique se o módulo WhatsApp está ativo no painel
2. Aguarde 30 segundos
3. Se continuar, recarregue a página
4. Se ainda não aparecer, entre em contato com o suporte

### O WhatsApp desconectou sozinho

**Normal:** Isso pode acontecer ocasionalmente.

**Solução:**
1. Volte ao painel
2. Vá na seção WhatsApp
3. Escaneie o QR Code novamente
4. O bot se reconectará automaticamente

### Posso usar o mesmo WhatsApp em múltiplos dispositivos?

Sim! O WhatsApp permite conexão em até 4 dispositivos simultaneamente (celular + 3 apps web).

### O bot responde automaticamente?

Sim, se você tiver o módulo "Assistente IA" ativo, o bot responderá automaticamente às mensagens dos seus clientes.

## 💰 Pagamentos

### Como comprar um módulo?

1. Vá em "PLANOS" no painel
2. Clique no módulo desejado
3. Escaneie o QR Code PIX
4. Faça o pagamento
5. O módulo será ativado automaticamente

### O pagamento não foi confirmado

**Tempo normal:** Até 10 minutos para confirmação.

**Se demorar mais:**
1. Tenha o comprovante do pagamento
2. Entre em contato com o suporte
3. Forneça o Order ID (mostrado no painel)

### Posso cancelar meu plano?

Sim, entre em contato com o suporte para cancelar. O cancelamento não é automático.

### Qual a forma de pagamento?

Atualmente aceitamos apenas PIX via Mercado Pago.

## 📦 Produtos

### Como adicionar produtos?

1. Vá em "PRODUTOS"
2. Clique em "+ Adicionar Produto"
3. Preencha as informações
4. Clique em "Salvar"

### Como fazer backup dos produtos?

1. Vá em "PRODUTOS"
2. Clique em "💾 Backup (Exportar)"
3. O arquivo será baixado automaticamente

### Como importar produtos em massa?

1. Crie uma planilha (Excel/Google Sheets)
2. Use este cabeçalho: `codigo, nome, descricao, preco, estoque, imagem`
3. Salve como CSV
4. Vá em "PRODUTOS"
5. Clique em "📥 Importar CSV"
6. Selecione o arquivo
7. Confirme

### Posso editar um produto?

Sim! Clique no botão ✏️ ao lado do produto para editar.

## 🖥️ PDV

### Como usar o PDV?

1. Ative o módulo PDV
2. Vá em "PDV CAIXA"
3. Digite o código do produto
4. O produto será adicionado ao carrinho
5. Para finalizar, pressione F2
6. Escolha a forma de pagamento
7. Digite o valor pago
8. O sistema calcula o troco
9. Confirme

### Atalhos do PDV

- F1 - Ajuda
- F2 - Pagamento
- F4 - Cancelar venda
- F6 - Sair

### O estoque diminui automaticamente?

Sim! Quando você finaliza uma venda no PDV, o estoque do produto é reduzido automaticamente.
