# 📚 Guia do Cliente - KRYPTON SaaS

Bem-vindo ao KRYPTON SaaS! Este guia vai te ajudar a configurar e usar o sistema.

---

## 🚀 Primeiros Passos

### 1. Fazer Login

1. Acesse o painel: `https://seudominio.com`
2. Digite seu usuário e senha
3. Clique em "Entrar"

### 2. Conectar WhatsApp

O WhatsApp é essencial para usar os módulos de automação.

**Passo a passo:**
1. Após fazer login, clique na sua empresa no painel admin
2. Vá para a seção "WhatsApp"
3. O QR Code aparecerá automaticamente
4. Abra o WhatsApp no seu celular
5. Vá em: Configurações → Aparelhos conectados → Conectar um aparelho
6. Escaneie o QR Code que aparece no painel
7. Pronto! Seu WhatsApp está conectado

**Dica:** Mantenha o WhatsApp conectado no seu celular para que o bot continue funcionando.

---

## 💰 Ativar Módulos

### Como Comprar Módulos

1. No painel da empresa, clique em "PLANOS"
2. Escolha o módulo que deseja (ex: PDV, Delivery, Website)
3. Clique no módulo
4. Um QR Code PIX aparecerá
5. Escaneie com seu app bancário
6. Faça o pagamento
7. O módulo será ativado automaticamente

### Módulos Disponíveis

- **Assistente IA 🤖** - Chatbot inteligente para responder clientes
- **Delivery 🚚** - Sistema de delivery para restaurantes
- **Agendamentos 📅** - Sistema de agendamentos para salões/clinicas
- **Catálogo 🛍️** - Catálogo de produtos online
- **PDV Frente de Caixa 🖥️** - Sistema de caixa para varejo
- **Website 🌐** - Site profissional para sua empresa
- **PIX Automático 💳** - Pagamentos PIX automáticos
- **WhatsApp 📱** - Automação de WhatsApp (incluso)

## 📦 Usando os Módulos

### Catálogo de Produtos

**Como adicionar produtos:**
1. Vá em "PRODUTOS" no menu lateral
2. Clique em "+ Adicionar Produto"
3. Preencha:
   - Código (código de barras)
   - Nome
   - Descrição
   - Preço
   - Estoque
   - Imagem (opcional)
4. Clique em "Salvar"

**Como editar produtos:**
1. Clique no botão ✏️ ao lado do produto
2. Edite as informações
3. Clique em "Salvar Alterações"

**Backup e Importação:**
- **Backup:** Clique em "💾 Backup (Exportar)" para salvar todos os produtos
- **Importar:** Clique em "📥 Importar CSV" para adicionar produtos em massa de uma planilha

### PDV Frente de Caixa

**Como usar:**
1. Ative o módulo PDV
2. Vá em "PDV CAIXA" no menu
3. Digite o código do produto ou escaneie com leitor de código de barras
4. O produto será adicionado ao carrinho
5. Para finalizar, clique em "F2" (Pagamento)
6. Escolha a forma de pagamento
7. Digite o valor pago
8. O sistema calcula o troco
9. Clique em "Confirmar"

**Atalhos:**
- F1 - Ajuda
- F2 - Pagamento
- F4 - Cancelar venda
- F6 - Sair

### Agendamentos

**Como configurar:**
1. Ative o módulo Agendamentos
2. Vá em "AGENDAMENTOS"
3. Configure os horários de funcionamento
4. Adicione profissionais (se necessário)
5. Defina os serviços oferecidos

## 💳 Configurar Pagamentos

### Mercado Pago

O sistema já está integrado com Mercado Pago para cobrança dos módulos.

**Para receber pagamentos PIX dos seus clientes:**
1. Configure sua chave PIX no painel da empresa
2. Vá em "MERCADO PAGO"
3. Insira sua chave PIX
4. Insira o nome do titular
5. Salve

## ❓ Perguntas Frequentes

### O QR Code não aparece

**Solução:**
1. Verifique se o módulo WhatsApp está ativo
2. Aguarde alguns segundos (pode demorar para gerar)
3. Se continuar não aparecendo, entre em contato com o suporte

### O WhatsApp desconectou

**Solução:**
1. Volte ao painel
2. Vá na seção WhatsApp
3. O QR Code aparecerá novamente
4. Escaneie novamente

### O pagamento não foi confirmado

**Solução:**
1. Verifique se você fez o pagamento corretamente
2. Se demorar mais de 10 minutos, entre em contato com o suporte
3. Tenha o comprovante do pagamento em mãos

### Como mudar meu plano?

**Solução:**
1. Entre em contato com o suporte
2. Solicite a alteração
3. O suporte irá ajustar seu plano
